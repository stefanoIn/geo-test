## TerraMind / TerraTorch

`src/encoders/terramind/terramind.py` imports the installed TerraTorch package;
GeoTest does not vendor the TerraMind backbone implementation in this wrapper.
The [TerraMind repository](https://github.com/IBM/terramind/blob/53d61da09213c2c3629931b6322f94cce617886a/LICENSE)
and [TerraTorch v1.2.5](https://github.com/IBM/terratorch/blob/v1.2.5/LICENSE)
publish Apache License 2.0 terms.

`TERRAMIND_STATS` in `src/data/preprocessing.py` reproduces selected numerical
entries from [TerraTorch v1.2.5 terramind_register.py](https://github.com/IBM/terratorch/blob/v1.2.5/terratorch/models/backbones/terramind/model/terramind_register.py).
The upstream file states `Copyright 2025 IBM Corp.`. GeoTest selects four
modalities and reorganizes their mean/std entries into modality dictionaries.
The attribution is scoped to these reproduced entries; the exact upstream
Apache licence is retained in [TerraTorch-LICENSE.txt](src/data/TerraTorch-LICENSE.txt).
The inspected upstream revision contains no separate NOTICE file.

## PANGAEA: architecture reference; source provenance unresolved

`src/baselines/unet.py` cites PANGAEA as an architecture reference. PANGAEA's
[repository licence](https://github.com/VMarsocci/pangaea-bench/blob/ca19b837a16797cd809225225b671473c7c93768/LICENSE)
is GPLv3. Comparing GeoTest with that revision's U-Net encoder and decoder shows
shared conventional operations (double convolutions, pooling, skip concatenation
and padding), but different class organization and forward-path implementation.
The introduction commit `7cf6ca10` does not establish whether source was adapted.
A comparison of the current Python files found no additional substantial
verbatim PANGAEA match beyond code also present in the original CROMA source.

Architecture similarity and a citation do not establish source-code copying.
No GPL licence has been assigned to GeoTest on that basis. Independent authorship
also cannot be established from a source comparison alone. Confirm the U-Net's
implementation provenance before treating this item as resolved; if source was
adapted, the relevant upstream notices and obligations require further review.

## Sen1Floods11: external data, not a code licence

GeoTest loads locally supplied Sen1Floods11 data. The current tracked tree does
not contain the dataset GeoTIFFs; no dataset files are added by these notices.
Dataset usage is distinct from redistributing imagery, labels, metadata or
historical notebook outputs containing them.

The [official dataset repository](https://github.com/cloudtostreet/Sen1Floods11)
requests citation of Bonafilia, Tellman, Anderson and Issenberg (2020),
*Sen1Floods11: A Georeferenced Dataset to Train and Test Deep Learning Flood
Algorithms for Sentinel-1*, CVPR Workshops. It contains no licence file in the
inspected revision. The four locally supplied STAC collection files under
`data/sen1floods11/catalog/` declare `license: proprietary`; this does not supply
redistribution permission. The upstream
[missing-licence issue](https://github.com/cloudtostreet/Sen1Floods11/issues/18)
also records the ambiguity. Obtain authoritative terms before redistributing
such dataset material. No dataset licence is inferred from public availability
or from third-party mirrors.

This review covers the current tracked sources and assets. It does not relicense
historical snapshots, external checkpoints, datasets or ignored reference files.
